# AGUA FINITA V10 / finished presentation review

The main presentation is `drawings/agua-finita-v10-booklet.pdf` (23 A3 pages). The single A0 board is `drawings/agua-finita-v10-a0.pdf`. The 9-page technical attachment is `drawings/agua-finita-v10-technical-appendix.pdf`. The cover and A0 hero use a clearly labelled **centre-district local aerial**, following the human request to fill the frame with readable city space. The whole-site boundary and six regions remain in the plans. The more distant southwestern city/production aerial is supporting context, never a whole-territory photograph.

Seven selected finished concept images are in `media/`: the southwest system aerial and one aerial plus one eye-level image for each of A03, B03 and C03. Raw controls are in `controls/`, never presented as finished images. Cameras, prompts, source/control/image hashes and selected/rejected visual review are recorded separately. Generation used built-in image_gen.imagegen; the exact model version was not exposed. Selected image files are unretouched copies of the generator output. The A03 tree-removal revision retains its earlier input in `trials/`.

`scene/geometry/` derives from V9, with four explicit open canopies and two pedestrian connections. The scene's master polygon is a rendering extent, not a revision of the full design area. No housing, jobs, education or IT capacity changes are credited. Source terrain is retained; conceptual building platforms avoid DEM clipping. Explicit PV rows follow V9 geometry. Procedural trees, PV and entourage are disabled. The public PDF retains the formal V9 planning evidence and replaces the node placeholders with the current views/plans/sections; it adds a shared locator and full zone/phase account.

This is a design-presentation review, not a new final submission or an automatic-check approval. No public website replacement is made. Yard-spur crossing detail, combined resource rights, fixed-pilot demand, livelihoods, regional alternatives and professional civil/environmental validation remain open. Images cannot prove these conditions.

Reproduce scene with `tools/presentation_v10.py`, controls with the project `scripts/render_views.py`, then composition with `tools/publish_v10.py`. Full generator prompts are retained; new AI finishes require visual review before selection. A discarded close-city trial was not used because it altered the bar-building grammar.
