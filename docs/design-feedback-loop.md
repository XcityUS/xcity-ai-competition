## Each iteration

1. Record a concrete observed problem with a figure, scope, geometry or data reference.
2. Check whether it follows from source ambiguity, template defaults, encoded checks, or the entrant's own decision.
3. Correct only the responsible layer; keep design freedom and avoid prescriptive forms, arbitrary areas or universal facility distances.
4. Update English/Chinese instructions, machine twins, templates and code when affected. Replace conflicting old statements rather than merely appending a contrary note.
5. Add a regression check for mechanically testable failures; document visual and professional reviews honestly.
6. Regenerate affected artefacts from current source geometry; compare figures, accounts and camera controls, not just a pass badge.
7. Publish the exact checked version with unresolved issues visible. Do not call a rule revision a finished design.
