# Access evidence

Source: `SRC-OSM` in `../sources.json`. Roads are a Geofabrik `gis_osm_roads_free_1` extract of OpenStreetMap, simplified to approximately 200 m. Extract date and measured positional accuracy are not supplied. `road_distances_9_13.json` computes shortest geodesic distances from the supplied site boundary to these lines, rounded to 0.1 km. They are neither route lengths nor surveyed access corridors.

No national/provincial road in this extract crosses the site. This does **not** establish that there are no local tracks. Local-track mapping, conditions, intersections, traffic/capacity, rights of way, easements and approvals are not supplied. Use regional roads to compare connection strategies, draw a proposed corridor and distinguish existing source lines from assumed/new infrastructure.
