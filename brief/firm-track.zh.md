# 设计事务所赛道 · 资质征集

> English: `brief/firm-track.en.md` · Español: `brief/firm-track.es.md`

XCITY AI Competition 设两个赛道。**AI Agent 赛道**在本仓库以 Pull Request 参赛；本文件说明的**设计事务所赛道**面向城市设计、规划与建筑事务所：同一块地、同一份任务书、同一个问题，由实名团队作答，通过资质审核参赛。

## 1. 程序

**第一阶段 · 意向与资质。** 符合第 2 条的事务所均可申请。不要求做设计：只看团队、经验与思路。主办方审核后确定入围名单。

**第二阶段 · 设计。** 入围团队收到第二阶段任务书、完整场地包与线上说明会，并有一段书面答疑期。作答范围与 AI Agent 赛道相同的三个尺度：整片场地的结构、自行划定的总体设计范围、十选三个重点节点（含渲染）。按要求完成提交的团队获得设计补偿。

**评审与选定。** 评审团按与 AI Agent 赛道相同的七个维度评审（`brief/evaluation.json`），两个赛道分开排名。入围团队线上陈述。

## 2. 谁可以申请

- 由依法设立的城市设计、城市规划、景观或建筑事务所牵头。
- 牵头方近十五年内完成或主导过至少一项城区尺度（100 公顷以上）的总体规划、新区或新城项目。
- 团队覆盖城市设计、景观与生态、能源与基础设施、水。合作方可在第一阶段列明，或在第二阶段补齐。
- 每家机构只能作为牵头方或成员参加一个团队。
- 申请时不要求有阿根廷当地合作方，选定团队的本地协作由 XCITY 安排。
- 主办方工作人员、评审团成员及其直系亲属不得参加。
- 个人、学生以及没有注册事务所的团队，欢迎参加 AI Agent 赛道。

## 3. 提交什么

一份 PDF，**不超过 20 页、20 MB**，中文、英文或西班牙文，包括：

1. **申请函**，牵头方签署（1 页）：机构名称、联系人、团队成员与分工。请使用申请表 `templates/firm-application-form.docx`（Word），作为这一页。
2. **机构简介**（不超过 3 页）：规模、办公地点、专业构成、相关奖项。
3. **主要人员**（不超过 4 页）：主创设计师与项目成员的简历。
4. **代表项目** 3–5 个，每个不超过 2 页：规模、你们的角色、业主、状态、年份。至少一项为总体规划或新区。
5. **思路说明**（不超过 2 页，不做设计）：你们会怎样面对这块地——水、能源与算力、已在运行的农光系统、分期，以及如果使用 AI 工具，打算怎样使用。

附件（不计入 20 页）：

- 执业资质或机构依法设立的证明；
- 签署的声明：团队成员与主办方、评审团之间不存在利益冲突。

## 4. 怎样申请

把 PDF 发到 **competition@xcity.ai**，邮件标题写 `XCITY AI Competition - Design practice track - <机构名称>`。主办方会确认收到，资质审核期间可能约一次简短的线上沟通。

### 答疑

- 发邮件到 **competition@xcity.ai**，标题写 `XCITY AI Competition - Design practice track - Question`；也可以公开提问：在本仓库开一个 Issue，标题以 `[firm-track]` 开头。
- 所有答复都公开发布在本仓库，对每位申请者相同，不写提问者是谁。不做私下答复。
- 答复只解释任务书，不改变任务书。确需修改的，直接改文件本身，并记入 `CHANGELOG.md`。
- 提问截止日期随正式规则公布。

## 5. 资质怎样审核

1. 经验与本项目的相关性——规模、气候、新聚落、能源与水。
2. 代表项目的质量。
3. 团队的能力覆盖。
4. 思路说明：读的是这块地，而不是一座泛泛的城市。

## 6. 随正式规则公布

提交截止日期、入围数量、评审团、设计补偿金额，以及选定团队之后的工作，随正式规则公布。此后以正式规则为准，变动记录在 `CHANGELOG.md`。
